Set up once

On each computer that prints. For 3-inch (80 mm) POS printers.

  1. Install the printer's Windows driver and print a Windows test page.
  2. Install Python 3 (tick "Add python.exe to PATH").
  3. Download the print helper, unzip it and double-click Start Mr Cafe print. Keep its window open (you may minimise it). Download print helper
  4. Come back here, choose the printers and press Test. If the browser asks to reach devices on your network, click Allow.

To start the helper with Windows: press Win+R, type shell:startup and put a shortcut to Start Mr Cafe print in that folder.
